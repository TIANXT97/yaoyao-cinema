# 夭夭影社（Yaoyao Cinema）

> **你家里的 NAS，就是你私人的爱奇艺。**
> 不下架、不看广告、不看会员，收藏片源永远 4K 原画质。

---

## 📺 这是什么

一台放在你家 NAS 上的**私人电影院**。可以把几十部、几百部视频收进来，自动配上漂亮的海报和简介，然后手机 / 平板 / 电脑随便一端打开就能看。

- **零转码**——NAS 不做任何视频压缩，只把视频文件原封不动一块块喂给你的设备（就像直接从硬盘拷给你那样），手机上看到的永远是原画质。**服务器 CPU 占用接近 0%**。
- **自动整理**——把零散的视频文件变成一张 Netflix 那样的海报墙。自动抓海报、简介、演员表（这步叫"刮削"），整个过程不用你动手。
- **全平台一套代码**——手机 Edge/Safari 打开网页就能用，"添加到主屏"就是原生 App；安卓手机有原生 APK 包装壳，iPad/Mac/PC 浏览器收藏一下就行。
- **完全私有**——数据全在你家里，不通过任何大厂服务器，没有任何广告，没有会员费。

## ⚡ 3 分钟搞定

### 决策者（老板 TIANXT）
如果你要评估这套东西有什么好、要不要做下一步取舍，看 [`AGENTS.md`](AGENTS.md)。Coding agent 的入门手册是 [`CLAUDE.md`](CLAUDE.md)。

### 看视频的人（你/家人/朋友）
1. 连家里 Wi-Fi，浏览器打开 **`http://192.168.31.235:9900`**
2. 手机: 点浏览器菜单里的"**添加到主屏**"（变成全屏 App 图标）
3. **安卓手机**: 直接装 APK（找老板要 `夭夭影社-release.apk` 文件）—— APK 比网页版体积更大、带 ExoPlayer 硬解,播放更流畅
4. 刷新片墙 → 看电影 → 拖动进度条零延迟

### 第一次进去没片怎么办
你把视频文件放进 NAS 的 **`/vol1/1000/私人影库/`** 文件夹（或者百度网盘、移动硬盘）。回到影院，点页面右上角**"扫描"**按钮，几秒后海报就长出来了。

### 开发者 / AI Agent 协作
完整的开发流程请到 [`CLAUDE.md`](CLAUDE.md)（给写代码的 AI agent 看） 和 [`AGENTS.md`](AGENTS.md)（给两只 AI agent 的合作契约看）。

代码改动链路是单向的：**任何 PC 改代码 → push 到 GitHub → NAS 端 `git pull && docker compose up -d --build` → 新版本上线**。

```bash
# 完整示例
git clone https://github.com/TIANXT97/yaoyao-cinema.git
cd yaoyao-cinema
# 改 server/api/stream.py ...

git add . && git commit -m "feat(...): ..."
git push origin main

# NAS 端拉新镜像并重启
ssh nas 'cd /vol1/1000/vibe-projects/yaoyao-cinema && git pull && docker compose up -d --build yaoyao-cinema'
```

## 📖 名词小词典

| 行话 | 人话 |
|---|---|
| **Direct Play / 直出** | 视频不做压缩加工，原画画质直接给你的设备播 |
| **刮削 (scrape)** | 自动从网上抓电影海报、简介、演员表，整理成海报墙 |
| **206 / 字节切片** | 视频文件被切成一小块一小块按需提供；你拖进度条时只重传你跳到的那一块 |
| **PWA** | 浏览器打开网页，"添加到主屏"就变成和 App 长得一模一样的全屏应用 |
| **Capacitor + ExoPlayer** | 安卓把网页套进原生壳里 + 播放器硬解码，比网页播放更流畅 |
| **Docker 容器** | 把整个服务（代码+依赖）打包成一个文件盒子，搬哪台机器都能跑 |
| **bind mount** | 让容器里的目录直接映射到宿主机某个文件夹，不用真的复制 |
| **git push** | 把你改的代码推到 GitHub，它是代码的**唯一权威版本** |
| **main 分支** | 代码的"正版"，所有人的改动最终都流向它 |
| **SSH 跳板 / 隧道** | 人在公司想管理家里 NAS，先 ssh 到一台云中间服务器再转回家里 |

## 📜 项目哲学

- **零画质损耗**：服务端只搬运字节，解码全部交给手机 GPU
- **非会员**：自建私有，零广告零流量结算
- **东方雅致**：纯白界面，拒绝网红风审美污染，回归阅读式浏览
- **私有元数据**：刮削引擎支持本地 NFO 与私有元数据源，摆脱对 TMDB/豆瓣的依赖
